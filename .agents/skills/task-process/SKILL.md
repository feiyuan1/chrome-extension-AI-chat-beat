# 任务定义

- 本 Skill 中的“任务”指的是 `tasks/<任务名>.md` 文件所对应的**一个独立任务**
- ”子任务“指的是 `tasks/<任务名>.md` 文件中 Task list 中的一项

# 完成子任务时：

- 简要记录当前子任务执行进展，确保可追溯

# 任务中断时

- 当任务未完成但流程已结束时，记录当前进度（包含已完成和未完成的子任务），以便后续按此继续开发。

# 当用户明确告知“任务全部完成”或你完成了一个多步骤任务并确认所有子任务已结束时：

- 主动向开发者提问，内容需具体到修改的代码，例如：
  - “我看到你刚实现了 `src/labels/ruleClassifier.ts`，需要为这个模块生成对应的单元测试吗？”
- 如果开发者同意，根据你刚刚完成的代码生成对应的测试用例；如果拒绝，则记录并结束流程。

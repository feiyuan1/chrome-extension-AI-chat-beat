# 处理 approval 的拒绝场景

当开发者拒请求时，Claude 必须按以下流程执行：

## 1. 要求明确反馈

- 在拒绝操作发生时，Claude 应主动提示开发者：“请说明拒绝的具体原因，或提供修改方向的建议。”

## 2. 调整方案

- 根据开发者提供的反馈，Claude 应重新评估并调整其修改方案。
- 调整后的方案应以清晰的方式（如列表或diff）再次展示给开发者。

## 4. 防止循环

- 如果调整后的方案再次被拒绝，Claude 应主动询问：“我注意到你再次拒绝了修改。是否需要我换一种完全不同的实现方式，还是终止当前任务？”
